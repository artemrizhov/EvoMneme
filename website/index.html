01 / THE PROBLEMCONTEXT IS FINITE. PROJECTS KEEP MOVING.

The next session
shouldn’t start
from zero.

The code survives the conversation.
Too often, the reasoning doesn’t.

A fresh session can mean rediscovering the same structure, tracing the same dependencies, and asking why an earlier choice was made. Loading more files only goes so far.

EvoMneme gives the agent a place to keep that understanding: a navigable graph of what exists, how it connects, and what was learned along the way.

↳ Not another copy of the code.
A map back to the evidence.
02 / THE APPROACHAGENT-MAINTAINED. SOURCE-GROUNDED.

Keep the map.
Follow the source.

The agent evolves the graph during active development within a shared, versioned schema. SQLite stores knowledge. The agent supplies the understanding.

01

Connect the structure.

Connect meaningful code entities and direct relationships from source the agent actually reads. Keep concise responsibilities, evidence, and source locations; preserve uncertainty explicitly.

CODE + RELATIONSHIPS
02

Preserve the why.

Keep useful findings and decisions with their reasons, constraints, and evidence. Technical, product, visual, and UI/UX knowledge can survive the session that uncovered it.

FINDINGS + DECISIONS
03

Retrieve with purpose.

Ask for compact, task-specific context. Follow relationships incrementally, then inspect original source when details matter. Expand what the task needs; record counts do not establish completeness.

CONTEXT + PROVENANCE
04

Reconcile as code changes.

During active work, the agent revisits affected knowledge, updates relationships, and corrects stale claims. Nothing independently interprets code or runs after sessions end.

04 / SMALL BY DESIGNTHE AGENT DOES THE THINKING.

Instructions first.
A thin tool layer.

EvoMneme is a portable instruction set for an authorized host project. Bound graph commands support navigation and maintenance; an optional SQL executor handles advanced queries in its local SQLite memory.

Read the live instruction set ↗
01 / CORE

A live skill

Connected through your agent’s native project instruction mechanism. The same live instructions load in every project session; verify that they actually do.

02 / STORAGE

Your project’s SQLite file

Nodes, relationships, and evidence use a shared, versioned schema. Knowledge and local state stay outside Git. Linked worktrees explicitly share one canonical host database.

03 / GRAPH COMMANDS + SQL

Navigate. Maintain. Inspect.

Use bound graph commands for ordinary exploration and updates. For advanced SQL, the optional Python standard-library executor accepts native statements and returns bounded results.

*

A working memory, not a promise of perfect understanding. This is an evolving project. Complete understanding, correct dependency detection, and efficiency gains are not guaranteed. The agent remains responsible for evidence, coverage, and keeping knowledge current.
